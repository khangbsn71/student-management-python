# Student Management System

A console-based Student Management System built with Python.

## Features

* Add new students
* View all students
* Search students by ID
* Update student scores
* Delete students
* Calculate average scores
* Classify academic performance
* Save data using JSON

## Technologies Used

* Python
* Object-Oriented Programming (OOP)
* JSON File Handling

## How to Run

```bash
python student_management.py
```

## Project Structure

```text
student-management-python/
├── student_management.py
├── students.json
└── README.md
```

## Example Functions

* Create student records
* Store student data in JSON format
* Calculate average scores automatically
* Display academic classification
* Manage student information through a console menu

## Project Purpose

This project was created to practice Python programming, object-oriented programming (OOP), file handling, and data management using JSON files.
